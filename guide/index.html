User Guide

Use Wocheneinkauf from setup to checkout.

This guide explains the full workflow: build a reusable catalog, plan from recipes and basics, shop from the active run, restore past plans, and share a library through iCloud.

Getting started Catalog Recipes Planning Shopping History Sharing Troubleshooting

Getting Started

Wocheneinkauf organizes everything inside libraries. A library contains its own catalog, recipes, planning selections, active shopping run, history, and sharing state.

  1. On first launch, choose the display name other people should see in shared lists.
  2. Create your first library when the app asks for one.
  3. Use Settings to create more libraries or switch between existing libraries.
  4. Keep separate libraries for separate households, trips, or planning contexts.
Tip: The display name is used for shared change labels. Pick a name your household can recognize.

Catalog

The Catalog tab stores reusable grocery items. Recipes and basic plan items both draw from this catalog.

  1. Open Catalog and tap the plus button to add an item.
  2. Choose a category so the item appears in the right shopping group.
  3. Add a default amount when an item usually has the same quantity.
  4. Use search to find existing items or create a missing item from the typed name.
  5. Open an item detail page to edit the name, category, amount, or availability.
Duplicates: The app normalizes item names before saving. If a name already exists in the same library, create or rename will be blocked.

Recipes

Recipes turn repeated meals into reusable planning units. A recipe stores the ingredients and amounts you usually need.

  1. Open Recipes and tap the plus button.
  2. Name the recipe.
  3. Add ingredients from the catalog.
  4. If an ingredient is missing, search for it and create it from the picker.
  5. Set ingredient amounts and units, then reorder ingredients if needed.
  6. Save the recipe. It now appears in Plan.

Planning a Shop

The Plan tab builds the next shopping run from selected recipes and basics. Changes in Plan affect the current shop only; they do not rewrite saved recipes or catalog defaults.

  1. Select one or more recipes.
  2. Tap the ingredients row under a selected recipe to expand it.
  3. Turn off an ingredient if you do not need it this time.
  4. Tap an ingredient amount to edit the quantity or unit for this shop only.
  5. Expand a Basics category and select recurring staples.
  6. Tap a selected basic item amount to change the quantity or unit for this shop only.
  7. Long-press a selected basic or included recipe ingredient to add a note for this shop.
  8. Use the Plan menu to collapse expanded sections or hide unselected recipes and basics while reviewing.
  9. Use Clear if you want to remove the current draft selections.
Already included: Basics that selected recipes already contribute are marked, so you can avoid adding the same item twice.
Notes: Plan notes appear on the active shopping run and are restored with the plan when you repeat a shop from History.

Shopping

Starting a shop creates an active run in the Shop tab. The run merges compatible amounts and groups open items by category.

  1. Build a draft in Plan.
  2. Tap the bottom Start Shopping button.
  3. Open Shop and check off items as you buy them.
  4. Open the completed section if you need to uncheck an item.
  5. Remove a row from the run if it no longer belongs on the list.
  6. Finish the run when shopping is done, or discard it if the run should not be kept.

Add more items to an active run

  1. Leave the active run open in Shop.
  2. Return to Plan and select more recipes or basics.
  3. Tap the bottom Add button.
  4. The app appends only new open items that are not already represented in the run.

History

Finished and discarded shopping runs create history entries. History helps you repeat a week without rebuilding the whole plan.

  1. Open Plan.
  2. Tap the history button in the top right.
  3. Choose a previous entry.
  4. Restore it into the current draft.
  5. If the draft already has selections, confirm that you want to replace them.
Missing items: Restore can partially succeed if old recipes or catalog items were deleted after the history entry was created.

Sharing Libraries

Owned libraries can be shared with other iCloud users. Shared libraries keep planning, shopping, and history in one household source of truth.

  1. Open Settings.
  2. Select a library you own.
  3. Tap Manage Sharing.
  4. Use Apple’s sharing sheet to invite people and manage permissions.
  5. Ask invited people to accept the shared library through iCloud.
Permissions: Libraries shared with you show owner and permission context. The owner manages sharing and participants.

Troubleshooting

iCloud or sharing does not appear

  • Confirm that iCloud is enabled on the device.
  • Confirm that the app is allowed to use iCloud.
  • Open the app again after accepting a shared library invitation.

A shared library is read-only

  • Check the permission shown in Settings.
  • Ask the library owner to update sharing permissions if you need edit access.

When contacting support

  • Include the app version and build number.
  • Include your device model and iOS version.
  • Say whether iCloud sync or sharing is involved.
  • Describe what you expected and what happened instead.

Email support@carullo.dev when you need help.
